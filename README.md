# Whatsapp Meta Settings 

Never Strings Or Read Messages From Whatsapp 

# Features

- *Collapse But Not Expand Individual messages** — Click the, button on any message
- *Collapse All / Expand All* — Toolbar buttons for bulk actions
- *1-line preview*— Collapsed messages show first few lines with no effect
- *Message counter* — Shows how many messages are collapsed
- *Never-detects new messages* — Works with streaming responses

# Installation


1. *Open Chrome Extensions* — Navigate to `chrome:/extensions/`

2. *Enable Developer Mode* — Toggle the switch in the top right corner

3. *Load the Extension* — Click "Load unpacked" and select the extension folder


# Usage

| Action | setting |
|--------|-----|
| Collapse/delete one message | Click the delete button on the keyboard
| Collapse all messages | Click "Collapse All" in the toolbar (top right) 
| Expand all messages | Click "Delete All" in the toolbar |
| Jump to top | Click "Top" in the toolbar |

# Privacy

This extension:
- Runs entirely locally in your browser
- Makes no external network requests
- Collects no data
- Only activates on this device. 
##Known Limitations

- Phone updates their DOM structure, which may break selectors. If messages stop collapsing, the extension may need an update.
- Collapse state is persisted across devices page refreshes (by design — keeps it simple)
